# Деплой ForkWork на Amvera Cloud

В репозитории уже лежат `Dockerfile`, `.dockerignore` и `amvera.yaml` — Amvera
собирает приложение по ним автоматически.

## Что важно понимать про эту платформу

- БД — встроенный `node:sqlite`, файл `data/forkwork.db`. Поэтому нужен
  **постоянный том**: в `amvera.yaml` он монтируется в `/app/data`
  (`persistenceMount`). Без него данные стирались бы при каждом деплое.
- Ключ `NEXT_PUBLIC_YANDEX_MAPS_API_KEY` — **публичный** (уезжает в браузер)
  и вшивается **на этапе сборки** → передаётся build-arg'ом, а не в рантайме.
- `ANTHROPIC_API_KEY` — **секрет** и нужен **в рантайме** → задаётся
  переменной окружения в панели Amvera (в репозиторий не коммитим).

## Шаги

1. **Создать проект** в панели Amvera на тарифе **с постоянным диском**
   (persistence). Тип проекта — приложение из Git / Docker.

2. **Залить код.** Либо подключить GitHub-репозиторий `Quonec/forkwork`,
   либо добавить git-remote Amvera и запушить:
   ```bash
   git remote add amvera <url-из-панели>
   git push amvera main
   ```

3. **Сборка.** Amvera увидит `meta.environment: docker` и соберёт образ по
   `Dockerfile`. Чтобы карта работала, передайте публичный ключ Яндекс.Карт
   как **build-переменную/аргумент сборки** в панели:
   `NEXT_PUBLIC_YANDEX_MAPS_API_KEY=<ваш_ключ>`.
   (Если в панели нет build-аргументов — впишите ключ в значение по умолчанию
   `ARG NEXT_PUBLIC_YANDEX_MAPS_API_KEY=` в `Dockerfile`; он публичный, это
   безопасно. Без ключа приложение тоже поднимется, карта покажет подсказку.)

4. **Секреты рантайма.** В разделе переменных окружения проекта добавить
   (по желанию) `ANTHROPIC_API_KEY=<ключ>` — тогда AI-агент отвечает моделью
   Claude. Без него работает встроенная эвристика.

5. **Порт.** Уже задан: `containerPort: 3000` в `amvera.yaml`, приложение
   слушает `0.0.0.0:3000`. Ничего настраивать не нужно.

6. **Запуск и домен.** После сборки Amvera поднимет контейнер и выдаст
   поддомен с HTTPS. Свой домен подключается в настройках проекта.

## Первый запуск

При старте БД создаётся и наполняется демо-данными автоматически
(на постоянном томе). Демо-аккаунты — см. `README.md`
(`admin@forkwork.ru` / `admin123` и др.).

## Обновление версии

Запушить новый коммит в подключённую ветку → Amvera пересоберёт образ.
Том `/app/data` сохраняется, данные пользователей не теряются.

## Бэкап БД

Достаточно скопировать файл `data/forkwork.db` с постоянного тома
(через файловый менеджер/SSH панели Amvera).
