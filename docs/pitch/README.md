# ForkWork — инвестиционный питч

Готовая презентация для инвесторов: **15 слайдов**, фирменный стиль ForkWork,
реальные скриншоты платформы и встроенные аналитические артефакты (рынок,
юнит-экономика, конкуренты, роадмап, use of funds).

## Файлы

| Файл | Что это |
|---|---|
| [`forkwork-pitch.html`](forkwork-pitch.html) | Интерактивный дек — открыть в браузере |
| [`forkwork-pitch.pdf`](forkwork-pitch.pdf) | Та же презентация в PDF (15 стр., 16:9) — для отправки инвесторам |
| `shots/` | Скриншоты платформы, использованные в слайдах |

## Как показывать

Открой `forkwork-pitch.html` в браузере (двойной клик). Управление:

- **← →** или **пробел** — листать слайды
- **F** — полноэкранный режим
- **P** — печать / экспорт в PDF
- клик по правой/левой половине экрана — вперёд/назад

Файл **самодостаточный**: без интернета, CDN и зависимостей (нужны только
картинки из папки `shots/` рядом).

## Структура (15 слайдов)

1. Обложка · 2. Проблема · 3. Решение · 4. Как это работает · 5. Live-commerce
(эфир + ИИ) · 6. Студия двух камер · 7. Роли и слой менеджеров · 8. Рынок
(TAM/SAM/SOM) · 9. Бизнес-модель · 10. Юнит-экономика · 11. Конкуренты ·
12. Что уже сделано · 13. Go-to-market и роадмап · 14. Команда · 15. Раунд и видение.

## Что обязательно заменить перед показом инвестору

Это шаблон «10/10» по форме; финальные данные — за основателем:

- **Слайд 14 «Команда»** — реальные имена, роли, достижения, эдвайзеры.
- **Слайд 15 «Раунд»** — сумма (`$500K` — плейсхолдер), use of funds, контакт.
- **Слайды 8 и 10 (рынок, юнит-экономика)** — цифры иллюстративные, отмечены
  сносками; подставь валидированные оценки и свои фактические конверсии.
- **Контакты** — `hello@forkwork.online` на обложке/закрытии.

## Пересборка PDF

PDF получен печатью HTML через Chrome (`@page` 1280×720, `printBackground`).
Чтобы обновить после правок — открой HTML и нажми **P** → «Сохранить как PDF»,
размер бумаги — альбомный, поля — нет, фоновая графика — включить.
