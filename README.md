# ForkWork: Chef's Fortune (FWSlot)

Слот-игра 5x3 с сервером и браузерной версией. Этот репозиторий деплоится на Amvera Cloud.

- `server/` - игровой сервер (Python, stdlib), кабинет администратора `/admin`, браузерная игра `/play/` (папка `server/web`).
- `math/` - математическая модель игры и её конфиг (нужен numpy).
- `Dockerfile`, `amvera.yml` - настройки Amvera такие же по форме, как у проекта ForkWork: сборка по Dockerfile, порт 3000, постоянный том `/data`.
- `DEPLOY-AMVERA.md` - как выкладывать и какие переменные окружения задавать.

Сервер стартует в режиме DEMO (игровые деньги, кошелёк выключен). Реальные TON включаются только переменными окружения (`FWSLOT_WALLET=ton` и остальные из DEPLOY-AMVERA.md) и требуют лицензии и правил площадки: прочитайте раздел 0 в DEPLOY-AMVERA.md.

Старая версия этого репозитория (ForkWork Scanner, `forkwork-scanner v0.9.27`) целиком сохранена в репозитории `Quonec/forkwork-amvera` и в истории этого репозитория (коммит `204577a`). Платформа ForkWork 0.8 лежит в ветках `v1-classic` ... `v6-yandex-map`.
