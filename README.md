# ForkWork — гастрономическая платформа

**Foodtech-платформа для взаимодействия поваров и горожан**: интерактивная карта, live-стримы с открытым чатом, личные чаты по согласию, заказ блюд, внутренний кошелёк, рецепты, отзывы, AI-агент и админ-панель.

MVP реализован по техническому заданию как полнофункциональное веб-приложение.

📊 **Карта приложения и бизнес-процессы (BPMN/Mermaid):** [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

---

## Быстрый старт

```bash
npm install
cp .env.example .env.local   # и впишите ключ Яндекс.Карт
npm run dev        # http://localhost:3000 (разработка)

# или продакшен-сборка
npm run build
npm start
```

### Карта

Карта работает на **Яндекс.Картах** (JS API 2.1). Получите бесплатный ключ в [кабинете разработчика Яндекса](https://developer.tech.yandex.ru/services/) (сервис «JavaScript API и HTTP Геокодер») и положите его в `.env.local`:

```
NEXT_PUBLIC_YANDEX_MAPS_API_KEY=ваш_ключ
```

Без ключа карта покажет подсказку, но список поваров и выбор продолжат работать (вся бизнес-логика от карты не зависит).

База данных SQLite создаётся и наполняется демо-данными **автоматически** при первом запуске (файл `data/forkwork.db`). Чтобы начать с чистого листа — просто удалите папку `data/`.

## Стек

- **Next.js 16** (App Router) + **TypeScript** + **Tailwind CSS 4**
- Дизайн **Яндекс Go × Uber** на палитре светлой охры: жёлтый солнечный акцент (кнопки, логотип, подсветка вкладок), фирменный «чёрный» Uber для контраста, плоские поверхности, жирный гротеск с плотным трекингом. Токены переопределены на уровне `@theme` в `globals.css` — сменить гамму можно в одном месте
- Метафора «гастрономического путешествия»: маршрутная форма «откуда → куда за вкусом» на главной, остановки-вехи в «Маршруте ForkWork», статус заказа как маршрут поездки с жёлтой линией прогресса
- Юзабилити как в райд-приложениях: нижняя навигация на мобильных, плавающая панель корзины «N позиций · сумма → Оформить», крупный поиск в каталогах, списки-строки со стрелками

## Архитектура

```
src/
├── lib/
│   ├── db.ts          # node:sqlite: схема (17 таблиц), сид демо-данных, ленивый синглтон
│   ├── auth.ts        # сессии (cookie + таблица sessions), bcrypt
│   ├── api.ts         # json/err-хелперы, requireUser(role)
│   ├── queries.ts     # типизированные выборки (повара с рейтингом, стримы, рецепты)
│   ├── types.ts       # доменные типы, статусы заказов, комиссия
│   └── format.ts      # форматирование FC/дат, плюрализация
├── app/
│   ├── api/           # 23 REST-маршрута: auth, chefs, orders, wallet, chats,
│   │                  # streams/[id]/messages (с симуляцией зрителей), kitchen,
│   │                  # admin, ai/assistant, ai/stream-analysis, …
│   ├── map/           # карта (Яндекс.Карты, клиентские фильтры)
│   ├── streams/[id]/  # комната эфира (чат-поллинг, реакции, AI-блок)
│   ├── chefs/[id]/    # профиль повара (+корзина, избранное, чаевые, чат)
│   ├── kitchen/       # кабинет повара
│   ├── cabinet/       # кабинет заказчика
│   ├── admin/         # админ-панель
│   └── …              # лендинг, рецепты, корзина, заказы, чаты, онбординг
└── components/        # Header, карточки, корзина (Context+localStorage), AI-виджет
```

**Платёжная логика (демо-упрощение):** при оформлении заказа кошелёк заказчика дебетуется на полную сумму, повару сразу зачисляется сумма минус 10% комиссии; при отмене — зеркальный возврат. Все движения — в `transactions`.

**Симуляция live:** сообщения «зрителей» генерируются сервером по расписанию от момента старта эфира (идемпотентно через `bot_cursor`), счётчик зрителей «дышит». Реальный видеопоток подключается заменой блока плеера (HLS/WebRTC — например, LiveKit) без изменения остальной логики.

## Ограничения MVP и дорожная карта

- Видео стрима — анимированная заглушка → LiveKit/WebRTC
- Поллинг чатов (2–3 с) → WebSocket/SSE
- Платежи виртуальные → интеграция платёжного провайдера, эскроу вместо мгновенного зачисления
- AI-агент: эвристика + опциональный Claude → мультимодальный анализ видеопотока
- Геокодинг адресов вручную (lat/lng в профиле) → автоматический геокодер
- Восстановление пароля, телефон/соцсети — заглушки

> Платформа не заменяет санитарные и медицинские проверки; AI-агент — вспомогательный модуль; финансовая логика для продакшена требует юридической адаптации под страну запуска.
